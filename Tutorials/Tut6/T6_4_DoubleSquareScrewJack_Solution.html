Tutorial 6.4  –  Double Square-Threaded Screw Jack

Problem Statement

A double (two-start) square-threaded power screw raises $W = 50$ kN. Major diameter $d = 25$ mm, pitch $p = 5$ mm, collar mean diameter $d_c = 51$ mm. Running friction: thread $f = 0.13$, collar $f_c = 0.1$.

(a) Find the lead, thread depth, mean diameter, and helix angle.  (b) Estimate the starting torque to raise and to lower the load.  (c) Estimate the efficiency when raising.

Given answers:  (a) $L = 10$ mm, depth $= 2.5$ mm, $d_m = 22.5$ mm, $\lambda = 8.05^\circ$   (b) $T_R = 351.93$ N·m, $T_L = 186.91$ N·m   (c) $28.12\%$

Solution

1
(a) Screw geometry
Try it first, then reveal ↓
Step 1 Lead, depth, mean diameter, helix angle

Two-start thread: $L = 2p = 2 \times 5 = 10$ mm. Square-thread depth is $p/2$, and $d_m = d - p/2$:

$$\text{depth} = \frac{p}{2} = 2.5\text{ mm} \qquad d_m = 25 - 2.5 = 22.5\text{ mm}$$
$$\lambda = \tan^{-1}\!\left(\frac{L}{\pi d_m}\right) = \tan^{-1}\!\left(\frac{10}{\pi \times 22.5}\right) = \tan^{-1}(0.1415) = 8.05^\circ$$

$$L = 10\text{ mm}, \quad \text{depth} = 2.5\text{ mm}, \quad d_m = 22.5\text{ mm}, \quad \lambda = 8.05^\circ$$

Geometrically identical to the T6.1 Acme jack — same $d$, $p$, and two-start lead. The difference is the square profile ($\alpha = 0$, no $\sec\alpha$) and the higher thread friction $f = 0.13$, which is why the torques below run a little higher.

2
(b) Starting torque to raise the load
Try it first, then reveal ↓
Step 2 Square-thread raising torque + collar, static friction

For a square thread ($\alpha = 0$):

$$T_R = \frac{W d_m}{2}\left(\frac{L + \pi f d_m}{\pi d_m - f L}\right) + \frac{f_c W d_c}{2}$$

Starting torque uses static coefficients $f_s = \tfrac{4}{3}(0.13) = 0.1733$ and $f_{c,s} = \tfrac{4}{3}(0.10) = 0.1333$.

Thread term:

$$T_{R,\text{thread}} = \frac{50\,000 \times 22.5}{2}\left(\frac{10 + \pi(0.1733)(22.5)}{\pi(22.5) - (0.1733)(10)}\right) = 562\,500 \times \frac{22.25}{68.95} = 181.5\text{ N}\cdot\text{m}$$

Collar term:

$$T_{R,\text{collar}} = \frac{0.1333 \times 50\,000 \times 51}{2} = 170.0\text{ N}\cdot\text{m}$$
$$T_R = 181.5 + 170.0 = 351.5\text{ N}\cdot\text{m}$$

$$T_R \approx 352\text{ N}\cdot\text{m} \quad(\text{book } 351.93\text{ N}\cdot\text{m})$$

3
(b) Starting torque to lower the load
Try it first, then reveal ↓
Step 3 Flip the thread sign; collar unchanged
$$T_{L,\text{thread}} = \frac{W d_m}{2}\left(\frac{\pi f d_m - L}{\pi d_m + f L}\right) = 562\,500 \times \frac{12.25 - 10}{70.69 + 1.73} = 562\,500 \times 0.03106 = 17.5\text{ N}\cdot\text{m}$$
$$T_L = 17.5 + 170.0 = 187.5\text{ N}\cdot\text{m}$$

$$T_L \approx 187\text{ N}\cdot\text{m} \quad(\text{book } 186.91\text{ N}\cdot\text{m})$$

The thread's lowering torque is positive but small ($17.5$ N·m); with $\tan\lambda = 0.1415$ and $f = 0.13$ the thread is marginally not self-locking on running friction, but the static bump plus the large collar keep $T_L$ firmly positive. Nearly all of $T_L$ is collar friction.

4
(c) Efficiency when raising
Try it first, then reveal ↓
Step 4 Useful work / input work, per revolution (running)

Use the running torque. Re-evaluating $T_R$ with $f = 0.13$, $f_c = 0.10$ gives $T_{R,\text{run}} = 283.1$ N·m (thread $155.6$ + collar $127.5$). Then:

$$e = \frac{W L}{2\pi T_{R,\text{run}}} = \frac{50\,000 \times 0.010}{2\pi \times 283.1} = \frac{500}{1778.7} = 0.2811$$

$$e = 28.1\% \quad(\text{book } 28.12\%)$$

Slightly higher than the T6.1 Acme jack (27.9%): the square thread avoids the $\sec\alpha$ friction penalty, so a touch more of the input work becomes useful lift even though its thread coefficient is the same $0.13$.

Common mistake 1: Treating "major diameter 25 mm" as $d_m$. Here 25 mm is the major diameter, so $d_m = 25 - p/2 = 22.5$ mm. (Contrast T6.2, where 25 mm was already the mean diameter.) Read which diameter the problem gives.

Common mistake 2: Applying the Acme $\sec\alpha$ factor to a square thread. Square threads have $\alpha = 0$, so $\sec\alpha = 1$.

Common mistake 3: Using the starting torque in the efficiency calculation. Efficiency is a steady-state ratio — use the running torque, or you will understate $e$.
